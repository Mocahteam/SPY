SPY Tips and Tricks

A collection of hidden features that aren't quite so hidden...

URL Parameters

SPY supports several parameters that can be passed through the URL. The following is a list of these parameters and their documentation:

  • lang: This parameter allows you to force the game to use a specific language (for example: https://spy.lip6.fr/game.html?lang=fr forces the game to load in French).
  • silent: This parameter disables the transmission of interaction traces to the server. When this parameter is enabled, the player's progress is therefore not saved.
  • clean: SPY allows users to customize the game settings (change interface colors, change the font, zoom in on the interface, etc.). This parameter resets all customized settings and restores the default configuration.
  • experimentationId: An experiment identifier that is added to the interaction traces. This parameter is useful when SPY is used as part of a research experiment and researchers want to easily retrieve all interaction data generated during that experiment (see openTraces.html). The experiment identifier is stored in the context extension.
  • level: This parameter allows you to load a specific mission directly, without going through the game's main menu. The mission file can be:
    • One of the missions listed in the SPY database. For example, the following URL directly loads the file Niveau02.xml from the Infiltration scenario: https://spy.lip6.fr/game.html?level=Levels/Infiltration/Niveau02.xml. A convenient way to retrieve the valid paths for each mission is to open the SPY scenario editor and look at the list of available missions (displayed on the left-hand side of the screen).
    • Hosted outside the SPY website, in which case the full URL must be provided. For example, with the following URL, https://spy.lip6.fr/game.html?level=https://panbricks.com/test.xml, the game will load the test.xml file hosted on panbricks.com. If you want to host a mission on a cloud storage service (such as Google Drive), see the following tip: Google Drive Links.

Google Drive Links

Have you created your own mission and would like your students to play it, but you don't have access to a server where you can host your file? You can use Google Drive for this purpose. The instructions below explain how to do it:

  • Host a mission on your Google Drive:
    • Upload your mission (XML file) to your Google Drive.
    • Change its file extension to ".txt".
    • Make the file publicly accessible.
    • Generating a public sharing link is not sufficient, because it points to a file preview page rather than directly to the file itself. You therefore need to retrieve the direct file access URL. Open your file using the public sharing link and retrieve its file ID from the sharing URL, which should have the following format: https://drive.google.com/file/d/[ID_TO_COPY]/view. Use this ID to construct the following URL: https://drive.google.com/uc?export=download%26id=[ID_TO_INSERT]. Then use this URL as the value of the level parameter.
  • Embed an image hosted on your Google Drive in a briefing text:
    • Upload your image to your Google Drive.
    • Make the image publicly accessible.
    • Generating a public sharing link is not sufficient, because it points to a file preview page rather than directly to the file itself. You therefore need to retrieve the direct file access URL. Open your file using the public sharing link and retrieve its file ID from the sharing URL, which should have the following format: https://drive.google.com/file/d/[ID_TO_COPY]/view. Use this ID to construct the following URL: https://drive.google.com/uc?export=download&id=[ID_TO_INSERT]. Then use this URL in the briefing text editor.
  • What if I want to embed a video or an audio file hosted on my Google Drive in my briefing? Unfortunately, this is not possible. The trick of converting the sharing URL only works for text files and images.

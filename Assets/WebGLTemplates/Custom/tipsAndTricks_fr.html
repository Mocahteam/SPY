Paramètres d'URL

SPY accepte quelques paramètres qui peuvent être passés en paramètre de l'URL. Voici ces paramètres et leur documentation :

  • lang : ce paramètre permet de forcer la langue du jeu (exemple : https://spy.lip6.fr/game.html?lang=fr forcera le jeu à charger en français).
  • silent : ce paramètre désactive l'envoie des traces d'interaction au serveur. Si ce paramètre est activé la progression du joueur n'est donc pas sauvegardée.
  • clean : SPY donne la possibilité aux utilisateurs de modifier les paramètres du jeu (modifier la couleur des interfaces, changer la police d'écriture, zoomer l'interface...). Ce paramètre permet d'annuler tout changement des paramètres pour revenir à la configuration par défaut.
  • experimentationId : identifiant de l'expérimentation à ajouter aux traces. Ce paramètre est utile lorsque SPY est utilisé dans le cadre d'une expérimentation et que les chercheurs souhaitent retrouver facilement l'ensemble des données d'intéractions générées lors de cette expérimentation (voir openTraces.html). l'identifiant de l'expérimentation est stoqué dans l'objet statement.context.instructor.account.name.
  • level : ce paramètre permet de demander au jeu de charger une mission directement sans passer par le menu principal du jeu. Le fichier de cette mission peut être :
    • une des missions référencée dans la base de donnée de SPY. Par exemple, l'URL suivante permet de charger directement le fichier Niveau02.xml du scénario Infiltration : https://spy.lip6.fr/game.html?level=Levels/Infiltration/Niveau02.xml. Un bon moyen de récupérer les chemins valides de chaque mission est d'ouvrir l'éditeur de scénario de SPY et de porter attention à la liste des missions disponibles (liste à gauche de l'écran).
    • hébergé à l'extérieur du site de SPY, dans ce cas l'url complète doit être renseignée. Par exemple avec l'URL suivante https://spy.lip6.fr/game.html?level=https://panbricks.com/test.xml le jeu chargera le fichier test.xml hébergé sur le site panbricks.com. Si vous souhaitez héberger une mission dans un Drive (comme GoogleDrive par exemple), consultez l'astuce suivante Liens GoogleDrive

Liens GoogleDrive

Vous avez créé votre propore mission et vous souhaitez la faire joueur à vos élèves mais vous n'avez pas accès à un serveur pour déposer votre fichier. Vous pouvez vous servir d'un GoogleDrive pour cela, les indications ci-dessous devraient alors vous intéressées :

  • Hébergez une mission dans mon GoogleDrive :
    • déposez votre mission (fichier xml) dans votre drive
    • renommez son extension en ".txt"
    • partagez votre fichier en accès public
    • générez ce lien public ne suffit pas car il renvoie vers une interface de visualisation du fichier et non le fichier lui même, il faut donc récupérer l'accès direct au fichier. Accédez à votre fichier via le lien public, récupérez l'identifiant de votre fichier dans l'URL de partage qui doit avoir la forme suivante https://drive.google.com/file/d/[ID_A_COPIER]/view, utilisez cet identifiant pour construire l'URL suivante https://drive.google.com/uc?export=download%26id=[ID_A_COLLER] et utilisez la comme valeur au paramètre level.
  • Pointez dans mon texte de breifing une image dans mon GoogleDrive
    • déposez votre image dans votre drive
    • partagez votre image en accès public
    • générez ce lien public ne suffit pas car il renvoie vers une interface de visualisation du fichier et non le fichier lui même, il faut donc récupérer l'accès direct au fichier. Accédez à votre fichier via le lien public, récupérez l'identifiant de votre fichier dans l'URL de partage qui doit avoir la forme suivante https://drive.google.com/file/d/[ID_A_COPIER]/view, utilisez cet identifiant pour construire l'URL suivante https://drive.google.com/uc?export=download&id=[ID_A_COLLER] et utilisez cette URL dans l'éditeur de texte de briefing.
  • Et si je souhaite dans mon briefing pointer une vidéo ou un son déposé dans mon GoogleDrive ? Malheureusement ce n'est pas possible, l'astuce de transformer l'URL de partage ne fonctionne que pour les fichier texte et les images.
